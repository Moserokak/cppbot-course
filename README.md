# C++ Bot — 36 заданий за один день

Учебный сайт с 6 мини-уроками и 36 упражнениями: 18 вопросов с автоматической проверкой и 18 задач на написание кода. Прогресс и черновики кода сохраняются в `localStorage` браузера.

Интерфейс и все задания доступны на русском и английском. Язык переключается кнопками RU / EN в шапке и сохраняется в этом браузере. Прогресс общий для обоих языков.

Светлая и тёмная темы переключаются кнопкой в шапке. Выбор темы сохраняется в браузере.

## Аккаунты и синхронизация

Для регистрации по email нужен проект Supabase. Пока файл конфигурации не заполнен, кнопка входа скрыта, а курс продолжает работать без аккаунта.

1. Создайте проект Supabase и выполните SQL из файла supabase/schema.sql в его SQL editor. Скрипт включает Row Level Security: пользователь читает только свой прогресс, а функция сохранения использует его идентификатор из авторизованной сессии.
2. В Supabase Auth настройте Site URL https://moserokak.github.io/cppbot-course/ и добавьте этот адрес в Redirect URLs для подтверждения email.
3. В supabase-config.js укажите URL проекта и publishable key. Никогда не вставляйте в клиентский код service_role или secret key.
4. Опубликуйте эти файлы. После входа локальный прогресс переносится в аккаунт; ответы и черновики сохраняются между устройствами.

## Запуск

Откройте `index.html` в браузере. Установка пакетов и сборка не нужны.

## Как работает проверка

- Вопросы с вариантами ответа проверяются автоматически.
- В задачах на C++ сайт показывает подсказку, пример вывода и образец решения, сохраняет черновик. C++ код на сайте **не компилируется**. Ученик запускает его в своём компиляторе или сверяет с образцом, после чего сам отмечает выполнение.
- Прогресс хранится только в текущем браузере и не синхронизируется между устройствами.

Русские задания и уроки находятся в `data.js`, английские тексты — в `en.js`, интерфейс — в `app.js`, оформление — в `styles.css`. Изображение робота создано для этого проекта.
